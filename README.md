# TapTales World · pitch

Pitch deck for TapTales World, a tap-and-tell guide for the statues of any city, generated from open data. Project by Luka Manojlovski for the FINKI course "Innovations in ICT" (2026). Static site, no build step.

The deck follows the course's chain of evidence: problem → alternatives → innovation claim → value → feasibility → validation → business model → project plan → budget → forecast → risks → IP. The five-year forecast on slide 17 is computed in the page from the assumptions printed under it.

Photos from Wikimedia Commons, credited on each slide. World outline from Natural Earth (world-atlas, public domain). Statue counts from taginfo.openstreetmap.org; arrivals from the UN Tourism World Tourism Barometer.
